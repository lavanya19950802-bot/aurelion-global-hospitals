# Aurelion Global Hospitals — React Website

This version redesigns the original Phani Bhushan Hospitals React application to closely follow the visual direction of the supplied reference video:

- Editorial luxury healthcare aesthetic
- Warm ivory/off-white background
- Black navigation and CTA areas
- Gold accent details
- Large Playfair Display serif headings
- Minimal Manrope body typography
- Moving specialty strip
- Founder note section
- Hospital network section
- Statistics band
- Dark closing CTA and footer
- Responsive mobile navigation and sticky mobile actions
- Appointment/contact modal

## Run

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```

## Customise

Replace the placeholder hospital locations, phone number, email, doctors, images, and Google Maps/WhatsApp links in `src/main.jsx`.

The project uses Vite 6.3.5 rather than `latest` to avoid the Rolldown native-binding installation issue on Windows/npm.
